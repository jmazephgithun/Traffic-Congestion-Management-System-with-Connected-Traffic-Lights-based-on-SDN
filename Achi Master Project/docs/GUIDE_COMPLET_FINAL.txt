PHASE B : TESTS RESEAU
================================================================================

Prerequis - Nettoyage avant chaque test
-----------------------------------------
  sudo mn -c
  sudo pkill -9 -f iperf
  sudo pkill -9 -f ryu-manager
  sudo ovs-vsctl --all destroy qos
  sudo ovs-vsctl --all destroy queue
  sudo rm -f /tmp/ctrl_server_*.log /tmp/bg_server*.log

Note technique critique
------------------------
  OVS noyau bypass les regles tc-htb appliquees par TCLink.
  La limite de bande passante DOIT passer par OVS QoS native :
    ovs-vsctl set port ap1-eth3 qos=@q ...
  Le script traffic_topology_corridor.py le fait automatiquement
  (branche 'else' pour mode sans QoS, branche 'if' pour avec QoS).

PARAMETRES DE L'ORCHESTRATEUR
================================================================================

  --ns-phase-idx 0    Phase NS_GREEN dans SUMO
  --ew-phase-idx 2    Phase EW_GREEN dans SUMO
  --min-green 10      Minimum 10s avant switch
  --max-green 45      Switch force apres 45s (equite)
  --hysteresis 0.15   Switch si queue adverse > 115% queue courante

Logique :
  busy >= 8.0  -> Ryu active QoS (set_queue:1 sur UDP:9999)
  busy <= 3.0  -> Ryu desactive QoS (hysteresis)
